# Описание бота для BotFather

Готовые тексты для настройки профиля бота. Уже применены через Bot API — можно скопировать сюда для хранения.

Ключевая мысль: **сервис бесплатный и заменяет Codex / Claude Code**. Название сервиса в публичных текстах не упоминается — оно открывается покупателю после оплаты.

---

## 1. Короткое описание — `/setabouttext`

Лимит 120 символов. Показывается в профиле бота.

```
Бесплатный сервис вместо Codex и Claude Code. Гайд по AI-агенту — 39 страниц. 219 ⭐.
```

Альтернатива:

```
Гайд по AI-агенту: 39 страниц практики. Оплата звёздами, выдача мгновенная.
```

---

## 2. Описание — `/setdescription`

Лимит 512 символов. Показывается на экране «Что умеет этот бот» до первого запуска. **Уже установлено в боте.**

```
Гайд по AI-агенту — 39 страниц практики.

Бесплатный сервис вместо Codex и Claude Code: работает как агент — ищет, пишет код, проверяет и отдаёт готовый файл: исследование, сайт, презентацию, документ.

Внутри: 10 задач с готовыми промптами, 25 промптов, 10 интеграций, план на 7 дней.

219 ⭐ · выдача мгновенная. Название сервиса и ссылка — после оплаты.
```

---

## 3. Команды — `/setcommands`

Уже установлены:

```
start — 🛒 Витрина магазина
buy — 💳 Купить гайд
mypurchases — 📥 Скачать купленное
service — 🔗 Сервис и ссылка
help — 🆘 Поддержка
paysupport — ❓ Вопросы по оплате
terms — 📄 Условия
```

Первое сообщение бот отправляет сам (текст в `texts.HELLO`), править его можно там же.

## 4. Текст для объявления / поста в канале

```
Внутри 39 страниц: 10 задач с готовыми промптами (садятся за один вечер), 25 формулировок, 10 интеграций и план на 7 дней.

Есть сервис, который заменяет Codex и Claude Code. И он бесплатный. Работает как агент: получает задачу, сам ищет информацию, пишет код, запускает его, читает ошибки и отдаёт готовый файл — исследование, лендинг, презентацию, отчёт с графиками.

У подписочных чатов такая задача съедает лимиты. Здесь лимит обнуляется сам, а агент проверяет себя до того, как отдаст результат.

Я собрал гайд: как ставить задачу, что он делает сам, где ошибается и какие формулировки дают результат с первого раза.

Название сервиса и ссылку присылаю сразу после оплаты — вместе с файлом.
219 ⭐ · @eternityaibot
```

Короткая версия для сторис / шапки профиля:

```
Бесплатный агент вместо Codex и Claude Code. Гайд на 39 страниц — как ставить ему задачи, чтобы получать исследования, код и презентации. 219 ⭐.
```

---

## 5. Что нельзя писать в публичных текстах бота

До оплаты название сервиса не упоминается нигде: ни в описании, ни в кнопках, ни в подписи к файлу, ни в заголовке счёта. Проверяется автоматически: `python tests/test_flow.py` — блок «Секрет до оплаты».

Название и ссылка меняются без правки кода — в `.env`:

```
SERVICE_NAME=Arena.ai
SERVICE_URL=https://arena.ai
SERVICE_AGENT_URL=https://arena.ai/agent
```

---

## 6. Бесплатный доступ для своих

В `.env`:

```
FREE_USERNAMES=asnaebp,vladmyaz
ADMIN_USERNAMES=asnaebp,vladmyaz
```

Эти пользователи получают гайд **и ссылку на сервис без оплаты**: при `/start` сразу приходит файл, в базе запись со статусом `free`. По нику же выдаются права админа — команды `/stats`, `/grant`, `/refund`.

Можно добавить числовые id: `FREE_USER_IDS=123456789,987654321`.
