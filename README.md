# Arena Store — Telegram-магазин с выдачей PDF-гайда

Бот-магазин в Telegram: продаёт **один файл** (PDF-гайд по AI-агентам) и выдаёт его автоматически после
оплаты в Stars. Разноцветные кнопки, карточка товара с обложкой, повторное скачивание, статистика.

**Ключевая механика:** до оплаты в интерфейсе нет ни названия сервиса, ни ссылки — только описание
продукта. Покупатель платит **219 ⭐** и получает тремя сообщениями: **название сервиса → ссылка → PDF**.

```
/start
 ├─ 🛒 Купить за 219 ⭐            ← зелёная кнопка
 ├─ 📖 Что внутри  🧾 Как это работает  ← синие
 ├─ ❓ Вопросы     🆘 Поддержка        ← красная
 └─ 📥 Мои покупки

после оплаты:  🔓 сервис + ссылка  →  📘 файл
               (вернуть ссылку: кнопка «🔗 Сервис и ссылка» или /service)
```

---

## Как запустить

Всё делается **на сервере**. Токен и настройки — из переменных окружения.

```bash
export BOT_TOKEN=123456:AA...      # токен от @BotFather
export DEMO_MODE=false             # перед продажами
./install.sh docker                # или ./install.sh systemd
```

Можно одной командой прямо на сервере (код скачается сам):

```bash
export BOT_TOKEN=123456:AA...
bash <(curl -fsSL https://raw.githubusercontent.com/<аккаунт>/<репозиторий>/main/setup.sh)
```

### Куда класть `.env`

**Никуда.** Переменные окружения — основной способ. Файл `.env` не обязателен:
если он есть в корне репозитория, Docker Compose сам его прочитает, а переменные окружения
всё равно имеют приоритет.

Бот в коде читает переменные окружения напрямую, поэтому работает в любом случае:
контейнер, systemd, CI, запуск руками.

### Ручная установка

```bash
git clone https://github.com/<аккаунт>/<репозиторий>.git
cd <репозиторий>
export BOT_TOKEN=123456:AA...
./install.sh docker
```

### Проверка

```bash
cd app && python3 bot.py --check
```


## Что нужно настроить перед продажами

| Переменная | Значение | Зачем |
|---|---|---|
| `BOT_TOKEN` | токен от @BotFather | Обязательно |
| `DEMO_MODE` | `false` перед продажами | Убирает кнопку «Снымитировать оплату» |
| `PRICE_STARS` | `219` | Цена в звёздах |
| `SERVICE_NAME` / `SERVICE_URL` / `SERVICE_AGENT_URL` | `Arena.ai` / `https://arena.ai` / `https://arena.ai/agent` | Что откроется покупателю после оплаты |
| `ADMIN_IDS` | ваш user_id | Уведомления о продажах, `/stats`, `/grant`, `/refund` |
| `FREE_USERNAMES` | `asnaebp,vladmyaz` | Кто получает гайд бесплатно |

Постоянно (чтобы не задавать при каждом запуске):

```bash
# /etc/environment — для всей системы
echo 'BOT_TOKEN=123456:AA...' | sudo tee -a /etc/environment

# или ~/.bashrc — только для вашего пользователя
echo 'export BOT_TOKEN=123456:AA...' >> ~/.bashrc
```

В systemd-режиме `install.sh` сам записывает токен в `/opt/arena-store/.env` (права 600),
юнит читает его через `EnvironmentFile`.

## Команды бота

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | все | витрина |
| `/buy` | все | оформить заказ |
| `/mypurchases` | покупатели | скачать купленное снова |
| `/service` | покупатели | название сервиса и ссылка |
| `/help`, `/paysupport` | все | поддержка |
| `/terms` | все | условия |
| `/stats` | админы | пользователи, заказы, звёзды |
| `/grant USER_ID` | админы | выдать доступ вручную |
| `/refund USER_ID` | админы | возврат звёзд |

## Обслуживание

```bash
# обновить код или заменить гайд (база и .env не затрагиваются)
./update.sh --db-backup

# резервные копии: база + PDF, срок хранения 30 копий
./backup.sh
```

Cron:
```cron
0 3 * * *  /opt/arena-store/backup.sh /var/backups/arena-store
```

## Оплата

Telegram Stars: валюта `XTR`, `provider_token` пустой, `protect_content=True`.
Возврат — `refund_star_payment` по `telegram_payment_charge_id`, команда `/refund`.

## Тесты

```bash
cd app && python3 tests/test_flow.py
```

Ожидаемый результат: `Итог: 92 проверки пройдено, 0 провалено`.

Тесты подменяют транспорт aiogram фейковой сессией и прогоняют весь путь покупателя:
витрина → «Что внутри» → «Купить» → демо-оплата → раскрытие сервиса + выдача PDF → повторное
скачивание, а также реальную ветку Stars (счёт → `pre_checkout_query` → `successful_payment`),
отклонение платежа с неверной суммой и бесплатный доступ для своих. Отдельный блок проверяет,
что **до оплаты название сервиса не появляется** ни в одном тексте, кнопке или заголовке счёта.

Сеть и реальный токен не нужны.

## Безопасность

- `.env` с токеном **не входит в репозиторий** (в `.gitignore`), права `600`.
- В `app/` нет секретов: все значения читаются из переменных окружения.
- Контейнер работает от непривилегированного пользователя, база вынесена в volume.

## Разноцветные кнопки

Цвет задаётся полем `style` (Bot API 9.0+). На клиентах старше февраля 2026 кнопки просто останутся без цвета — логика не ломается.

| Стиль | Цвет | Где используется |
|---|---|---|
| `success` | зелёный | «Купить за 219 ⭐», «Оплатить», «Скачать гайд» |
| `primary` | синий | «Что внутри», «Как это работает», «Вопросы», «Мои покупки» |
| `danger` | красный | «Поддержка», «Отмена» |

Клавиатуры собраны в `keyboards.py` — по одной функции на экран.
